Garamond Mono
=============

Garamond Mono is a monospace old-style serif font.
This is based on EB Garamond.

Weights: Regular, Medium and Bold, each with an italic. Medium is derived from
Regular at build time by `makemedium.py`, which needs fontTools, skia-pathops,
booleanOperations, freetype-py and numpy.
